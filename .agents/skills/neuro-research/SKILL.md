# Neuro research workflow

1. State the scientific question before selecting data.
2. Prefer primary papers, official dataset pages, and official API documentation.
3. Record dataset name, version/snapshot, source URL, citation, license/terms, and access date.
4. Distinguish connectome structure from neural dynamics; a graph is not automatically a runnable brain model.
5. Label measured, simulated, synthetic, and inferred data separately.
6. For bulk data, use documented downloads rather than scraping interactive sites.
7. Never invent cell types, neurotransmitters, synapse counts, or causal interpretations.
8. Produce a short evidence table: claim, source, exact support, limitation.
9. Save a machine-readable provenance manifest with each imported dataset.
10. Do not claim that a fly model is equivalent to a human BCI or Neuralink implant.
